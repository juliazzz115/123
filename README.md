# Трекер статусов клиентов

Веб-приложение для отслеживания статусов клиентов с двумя режимами работы.

## Возможности

### Режим А: Подал сам → Пометить → Проверить
Три колонки для отслеживания базового процесса.

### Режим Б: Оплатил → Подано → Помечено → Проверено
Четыре колонки для расширенного отслеживания процесса.

## Как использовать

1. **Открыть приложение**: Откройте файл `index.html` в браузере

2. **Выбрать режим**: Выберите нужный режим работы (А или Б)

3. **Добавить клиента в таблицу**:
   - Выберите клиента из выпадающего списка
   - Нажмите "Добавить в таблицу"

4. **Создать нового клиента**:
   - Введите имя в поле "Имя нового клиента"
   - Нажмите "Создать клиента" или Enter

5. **Отметить статусы**: Используйте чекбоксы для отметки выполненных этапов

6. **Удалить клиента**: Нажмите кнопку "Удалить" в строке клиента

## Особенности

- Автоматическое сохранение данных в браузере (localStorage)
- Переключение между режимами без потери данных
- Адаптивный дизайн для мобильных устройств
- Уведомления о действиях
- Предустановленные клиенты для быстрого старта

## Запуск

Просто откройте `index.html` в любом современном браузере. Никаких дополнительных зависимостей не требуется.
